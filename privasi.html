Kebijakan Privasi / Privacy Policy

Keuangan MPD CORP · berlaku sejak 11 November 2026 / effective 11 November 2026

1. Ringkasan

Keuangan MPD CORP adalah aplikasi desktop Windows untuk penggunaan internal MPD CORP. Data keuangan disimpan di komputer pengguna. MPD CORP sebagai pengembang tidak menerima, mengumpulkan, atau menyimpan data pengguna di server mana pun.

Summary. Keuangan MPD CORP is a Windows desktop application for internal use by MPD CORP. Financial data is stored on the user's computer. MPD CORP, as the developer, does not receive, collect or store any user data on any server.

2. Data Google yang digunakan

Hanya jika pengguna memilih fitur Pencadangan dan menghubungkan akun Google, aplikasi meminta izin berikut:

  • openid & email: untuk menampilkan alamat email akun yang terhubung di layar Pencadangan.
  • https://www.googleapis.com/auth/drive.file: untuk membuat folder "Backup Keuangan MPD CORP" serta mengunggah, menampilkan daftar, dan mengunduh file cadangan yang dibuat oleh aplikasi ini saja. Aplikasi tidak dapat melihat atau mengubah file Google Drive lain.

Google user data. Only if the user chooses the Backup feature and connects a Google account, the app requests: openid & email (to show which account is connected) and drive.file (to create the folder "Backup Keuangan MPD CORP" and to upload, list and download backup files created by this app only). The app cannot see or modify any other Google Drive files.

3. Cara data digunakan dan disimpan

  • File cadangan berisi data keuangan aplikasi dan disimpan di Google Drive milik pengguna sendiri. Hanya pengguna yang memiliki akses.
  • Token login Google disimpan terenkripsi (Windows Data Protection) di komputer pengguna, tidak dikirim ke pihak lain.
  • Data Google tidak dijual, tidak dibagikan kepada pihak ketiga, tidak dipakai untuk iklan, dan tidak dipakai untuk melatih model AI.
  • Data hanya dikirim langsung antara komputer pengguna dan layanan Google (accounts.google.com, oauth2.googleapis.com, www.googleapis.com) melalui koneksi terenkripsi (HTTPS).

Use and storage. Backup files contain the app's financial data and are stored in the user's own Google Drive; only the user has access. The Google sign-in token is stored encrypted (Windows Data Protection) on the user's computer and is never sent to anyone else. Google user data is not sold, not shared with third parties, not used for advertising and not used to train AI models. Data travels only directly between the user's computer and Google services over HTTPS. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. Menghapus akses dan data

  • Klik Putuskan di menu Pengaturan → Pencadangan untuk mencabut izin dan menghapus token dari komputer.
  • Izin juga dapat dicabut di myaccount.google.com/permissions.
  • File cadangan dapat dihapus kapan saja dari folder "Backup Keuangan MPD CORP" di Google Drive pengguna.

Removing access and data. Click Putuskan (Disconnect) in Settings → Backup to revoke access and delete the token from the computer, or revoke at myaccount.google.com/permissions. Backup files can be deleted at any time from the "Backup Keuangan MPD CORP" folder in the user's Google Drive.
